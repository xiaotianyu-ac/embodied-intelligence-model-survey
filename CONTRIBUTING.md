# Contributing evidence

Contributions should identify an original paper, official model card/code, or direct deployment source and explain the material change. Preserve the evidence cutoff and source date separately. Include both report languages or clearly identify translation work still needed before release.

Model claims need a version and operating conditions. Relationship claims need a type: explicit reuse, series evolution, method combination, system complementarity, or analytical comparison. Scores require matching benchmark and protocol; unsupported universal rankings will not be incorporated.

Edit the modules under `records/research/`, then use the update workflow in `intent/derived/update-workflow.md`. Third-party code, weights, videos, and full paper PDFs should be linked rather than copied without appropriate permission.
