# Topic and intended use

This survey supports researchers and engineers evaluating embodied-intelligence model designs. The primary deliverable is a self-contained bilingual report, accompanied by model decompositions, evidence-backed relationships, data/benchmark/product matrices, editable diagrams, and reproducible report builds.

The main emphasis is the reasoning behind each model: which failure mode it targets, where knowledge enters, how action is represented, what training contributes, and how prediction reaches feedback control. It avoids a single league table for incompatible benchmarks.
