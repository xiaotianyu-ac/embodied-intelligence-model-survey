## 表征、层级推理与世界模型：从理解场景到预测行动后果

这一技术群不能按一个“模型越大、机器人越强”的排行榜理解。表征模型回答“当前状态怎样编码”，层级模型回答“下一步做什么”，动作策略回答“执行怎样的控制”，世界模型回答“假如执行这些控制，之后会发生什么”。一个系统可能覆盖多个角色，但只有完成感知、决策、动作执行和反馈更新，才形成真实机器人闭环。以下将论文实验、官方产品说明与本文分析分开；所有版本核验截至 2026-09-11。

### SayCan、PaLM-E、EmbodiedGPT：语言推理怎样接上机器人

**SayCan（2022）**解决语言计划缺乏可执行性的问题。输入是用户指令、已经选择的技能，以及当前状态下各技能的可供性评分；语言模型估计技能对任务的相关性，技能价值函数估计执行成功概率，两者共同决定下一技能。训练负担主要在已有技能策略和价值函数，推理时执行技能再选择下一步。它把语义常识与机器人能力分工连接起来，并没有把语言模型变成关节控制器。尤其应注意，原版 SayCan 对环境的反馈主要来自当前价值函数，不能因此声称已经完整解决失败检测与重规划；官方网站明确指出该限制。公开版本是桌面仿真实现，不等于完整移动操作栈开放。[W001]

**PaLM-E（2023）**进一步把图像和连续状态编码成与文本同维的嵌入，插入解码器语言模型。用机器人规划、图文与语言任务联合训练，输出文本计划，再由底层策略执行；视觉反馈可以进入后续计划。它与 SayCan 的关键差别是**将环境观测直接放进语言推理**，不是简单换一个更大的文本模型。562B 版本体现的是多模态语义迁移，不代表562B网络以伺服频率输出电机命令。数据混合、感知落地和底层动作能力共同决定系统效果。[W002]

**EmbodiedGPT（2023）**以 Ego4D 衍生的 EgoCOT 子目标数据适配7B语言模型，采用前缀调优，并从生成计划的查询中提取任务相关特征服务控制。其意义是学习“视觉—子目标—控制特征”的接口，而不仅仅把长指令展开成文字。Franka Kitchen和Meta-World中的改进应限于论文设置；文本推理质量与真实接触控制可靠性仍需分别验证。[W004]

### VIMA 与 VoxPoser：任务接口和几何落地的两条路线

**VIMA（2022预印本、ICML 2023）**将文字、目标物体图像、示范帧混合成一个任务提示。T5编码提示，带交叉注意力的因果Transformer读取提示和交互历史，逐步生成操作动作。600K+专家轨迹和四级泛化划分，使问题从“某个指令会不会做”转为“物体、组合、任务模板改变后是否仍会做”。这是一种以物体为中心的多模态条件策略；不能因为存在文字输入，就把它等同于继承互联网LLM能力的所有VLA。主要证据来自程序生成的桌面仿真任务，感知前端和真实动作分布迁移仍是额外问题。[W003]

**VoxPoser（2023）**从另一方向解除固定技能库限制：语言模型生成程序，调用视觉语言组件构造三维可供性图、避障/姿态/速度等约束图，运动规划器在这些目标上寻找末端轨迹。视觉变化后重新计算地图并滚动规划，使高层语言输出不必每个控制周期重新生成。它把语言知识落在可检查的几何目标上，适合明确空间约束；代价是对分割、相机标定、可达性和动力学假设敏感。其“无需额外训练”指核心组件的组合使用，不意味着不需要预训练感知模型、控制器或真实系统集成。[W005]

### R3M 与 VC-1：视觉编码器是基础设施，不是完整策略

**R3M（2022）**利用Ego4D的人类视频，以时间对比、视频语言对齐和紧凑性约束训练视觉表征，冻结编码器后再学机器人控制。**VC-1（2023）**采用MAE式视觉预训练，并通过CortexBench跨导航、移动操作和灵巧操作等任务系统考察模型与数据规模；域适配能显著改变结论。两者共同说明互联网视觉经验可以降低下游数据需求，但不直接给出动作、长期规划或物理状态转移模型。[W006][W007]

分析上，R3M/VC-1与VLA不是前后代替代关系：它们可以成为策略的感知模块，也可作为检索、奖励或世界模型的编码器。评估编码器时须固定下游策略、演示数量、相机和微调协议；只比较编码器名字会把控制头和训练数据的作用混在一起。

### PerAct → RVT，以及3D Diffuser Actor：几何归纳偏置与生成动作的结合

**PerAct（2022）**将RGB-D重建为体素，结合语言，通过Perceiver处理三维patch，以分类方式选择下一末端位置体素及离散姿态/夹爪状态。核心思路是令观测与动作共享三维坐标系，使少量示范更容易约束六自由度操作。公开实验涵盖18项RLBench任务和少量真实机器人任务；体素分辨率、显存与标定误差构成明确代价。[W008]

**RVT（2023）**针对密集三维表示的计算开销，把三维场景重新渲染成围绕工作空间的虚拟视角，用跨视图注意力融合，再预测夹爪位姿。它与PerAct在任务与三维动作目标上接近，主要改变**三维信息的计算表达**，因此是较清楚的效率改进关系；论文的训练与推理加速只适用于其硬件、实现和相同性能目标条件。[W009]

**3D Diffuser Actor（2024）**把上述几何路线与扩散策略结合：语言和带深度的场景编码为三维token，将加噪的末端旋转/平移也表示成token，借助三维相对注意力逐步去噪。它解决的是多峰动作分布和视角泛化，预测对象是**动作而非未来视频**。RLBench中下一关键位姿还需底层运动规划器到达。官方实现特别记录了四元数`wxyz/xyzw`及不同RLBench协议的差异，说明坐标约定与评测环境本身会改变结果；不能把不一致协议下的成功率排成统一榜单。[W010][W011]

### DreamerV3：在潜空间学习后果，在想象中改进策略

**DreamerV3（2023预印本，2025 Nature论文）**是模型式强化学习算法，不是一个已在所有机器人上预训练好的通用控制权重。它从交互数据学习循环状态空间模型，以潜变量预测状态演化、奖励和终止；再在想象轨迹上优化actor–critic，实际行动后将新经验加入训练。归一化、目标变换和损失平衡用于提高跨任务稳定性。[W012][W013]

它与视频世界模型的差异在于：控制优化发生在紧凑潜空间，训练时可以有图像重建，但不必在每次规划时生成可观看视频；与常规VLA的差异则是，策略改进依赖环境后果和奖励，而非仅拟合演示动作。统一超参数跨任务工作不等于一个权重跨任务零样本成功。探索成本、奖励设计和模型误差仍限制真实机器人的直接使用。

### UniSim：视频生成器作为策略训练环境

**UniSim（2023预印本、ICLR 2024）**用多来源图像、视频、导航与机器人数据训练条件视频生成器；条件既可以是高层语言行为，也可以是低层控制。推理时输入当前观测与行为，生成后续视觉经验，反复调用形成交互环境。论文用它生成经验来训练高层规划器和低层强化学习策略，并展示特定真实任务的迁移。[W014][W015]

其贡献是将“生成视频”变成“按动作产生训练轨迹”的工具。本文分析认为，扩展到工程系统必须检查机器人动作是否真正改变预测分布、接触失败是否会被模型忠实呈现，以及策略是否利用了生成器漏洞。此处UniSim指Yang等的交互生成模型，不是同名的自动驾驶神经传感器仿真论文。

### Genie 1 → 2 → 3：可交互环境逐代发展，物理控制结论仍需单独成立

**Genie（2024）**由视频tokenizer、潜动作模型和动态预测器组成，从没有真实动作标签的视频中学习可控环境；潜动作是从帧变化推断的控制变量，不能直接视作真实机器人关节指令。**Genie 2（2024-12）**采用自回归潜空间扩散，以历史潜帧和用户动作生成下一帧，展示可交互三维环境。**Genie 3（2025-08）**官方展示720p、24fps和数分钟一致交互，并在2026年通过Project Genie原型提供部分用户体验。[W016][W017][W018][W019]

这一系列推动的是环境生成、交互持续性和智能体训练载体。Genie 3公开说明直接动作空间有限，提示触发的世界事件未必由智能体自身执行，多主体交互也仍有困难。因此，能在生成场景中行走、改变天气或生成机器人视频，不构成机械臂精确接触、真实物体守恒、力矩闭环或长期安全性的验证。Genie 3完整训练语料与底层架构未在本章所核验的官方页面公开，不能把Genie 2的实现细节当作Genie 3已证实架构。

### GR-1 与 GR-2：视频预训练怎样变成直接动作能力

**GR-1（2023）**先从大规模视频学习未来视觉变化，再以机器人轨迹适配；GPT式序列模型读取语言、图像历史和机器人状态，同时预测未来图像与动作。未来预测充当表征学习和时序监督，部署时仍可直接读取动作头，不必显式搜索所有未来。**GR-2（2024）**扩大到3800万视频片段、500亿以上token的预训练，再联合微调视频与动作预测。[W020][W021][W022]

这条线处在VLA与世界模型交界：比静态图文预训练多了动态经验，比纯模拟器多了可执行动作输出；但“同时预测画面和动作”并不自动说明推理时使用模型预测控制。GR-2的97.7%对应105项任务的Simple设置，未见操作设置明显更难，不能外推为开放家庭或未知机器人成功率。[W036]完整预训练语料与复现条件需单独审查。

### V-JEPA 2 / 2-AC 与 V-JEPA 2.1：不重建像素的预测与规划

**V-JEPA 2（2025）**通过遮挡视频的潜特征预测训练编码器和预测器，避免把全部资源用于逐像素重建。**V-JEPA 2-AC**进一步使用不足62小时DROID机器人视频及动作记录训练动作条件动态预测器，以目标图像对应的特征作为规划目标，在真实Franka上滚动选择动作。所谓零样本是对部署环境/任务不再采集专门训练数据，不是从完全无动作数据的视频直接得到任意机器人控制。[W023][W024][W026]

**V-JEPA 2.1（2026-03）**对可见与遮挡token都施加密集预测损失，引入多层自监督与图像/视频tokenizer，并扩展模型和数据规模。机器人部分复用2-AC的预测器架构、公开代码和规划协议，替换视觉编码器后，在DROID上重新训练动作条件预测器；这不是直接继承已训练的2-AC预测器权重。论文Table 6中，同样约3秒规划预算下杯子抓取由60%到70%；80%的结果使用更长规划、约14秒。也就是说，常被概括的20个百分点提高同时包含了规划预算变化。每项技能只有10个测试任务，论文还指出夹爪时序会导致失败，因此不能声称已实现稳定实时通用操作。[W025][W026]

分析上，JEPA路线选择“保留对任务有用的变化、忽略不必要像素细节”，视频生成路线选择“保留可观看的多模态未来”。两者并不互斥：潜空间规划可降低搜索成本，像素生成可用于人类审查和合成数据；关键是所保留的信息是否足以预测接触、遮挡和失败。

### Cosmos Predict、Cosmos Policy 与 Cosmos 3：同一品牌内三种不同能力

**Cosmos Predict 2.5**是可接受文本、图像或视频的世界视频生成模型；**Transfer 2.5**侧重深度、边缘、分割等条件下的场景转换。它们首先是数据/环境生成组件，不应直接等同于机器人策略。[W027]

**Cosmos Policy（2026-01）**则明确跨过动作边界：将Cosmos-Predict2-2B的视频潜帧槽复用于动作块、未来观测/本体状态和值，单阶段以目标平台示范后训练。同一个模型既能直接产生动作，也能采样多条候选行动，预测未来并按价值排序。论文分别报告直接策略和带规划设置，后者还可利用策略运行数据改进世界模型和值函数。工程上必须同时比较行动延迟、采样条数与成功率，不能把额外搜索带来的收益归给相同成本的直接策略。[W028][W035]

**Cosmos 3（2026-05发布，核验至9月）**进一步以Mixture-of-Transformers组合自回归推理塔与扩散生成塔，支持视觉理解、世界预测及动作生成。当前官方仓库列出Super 64B、Nano 16B、Edge 4B，并列出DROID后训练策略权重。Edge存在视频转换与分辨率限制；推荐端侧硬件并不表示所有模式都达到实时。核验的仓库当前许可证为OpenMDW-1.1，不能沿用旧Cosmos版本的许可证描述。完整预训练重现性、具体硬件延迟和陌生本体迁移需根据对应权重另测。[W029][W030]

### GAIA-2 → GAIA-3 → GAIA-4：自动驾驶世界模型的范围与启示

**GAIA-2（2025-03）**通过动作与结构化条件控制多摄像头未来生成；**GAIA-3（2025-12）**把重点推进到自动驾驶评估；**GAIA-4（2026-08）**官方展示让AI Driver的输出改变下一时刻模拟传感器输入，并联合生成相机与雷达数据。其world-on-rails模式令其他道路参与者沿真实日志轨迹运动，提供受控反事实比较；官方也说明可开启reactive agents，让选定参与者回应自车。[W031][W032][W033]

它们是驾驶领域的数据与验证基础设施，不能作为机械臂或人形机器人通用操作模型的直接证据。可迁移的方法论是：**评估世界模型应同时评估生成保真度、闭环行为一致性和结果一致性**。可观看的视频相似度只覆盖第一层，真实安全效果还受行为模型、传感器、场景覆盖和反事实假设限制。GAIA-4的详细网络与训练语料未在所核验官方页面充分公开，故保持“官方系统进展”证据等级。

### 模型之间的关系与架构选择

| 关系 | 技术解释 | 关系性质 |
|---|---|---|
| SayCan → PaLM-E | 从语言评分加可供性接口，转向直接读视觉/连续状态的语言规划 | 本文比较；不声称权重继承 |
| R3M / VC-1 ↔ 动作策略 | 可复用感知表示，下游控制头仍要训练 | 模块互补 |
| PerAct → RVT | 保留三维动作落地，改变几何表示与计算路径 | 论文明确比较 |
| 几何策略 + 扩散策略 → 3D Diffuser Actor | 三维相对注意力为动作去噪提供空间条件 | 论文明确方法融合 |
| GR-1 → GR-2 | 视频预训练、联合视频动作建模向规模化延伸 | 系列与方法延伸 |
| V-JEPA 2 → 2-AC；2.1编码器＋2-AC框架 | 编码器系列扩展；复用预测器架构与规划协议并重新训练 | 分支扩展与框架复用，不等同于权重继承 |
| Cosmos Predict2 → Cosmos Policy | 把预训练视频模型后训练成动作/未来/价值联合模型 | 明确初始化关系 |
| Cosmos旧系列 → Cosmos 3 | 以推理与生成双塔统一多类能力 | 官方架构演进；不等同逐权重继承 |
| Genie / UniSim / GAIA ↔ 策略 | 生成交互训练或评估环境，策略负责选择动作 | 系统分工 |
| Dreamer ↔ VLA | 前者通过动态与奖励学习改进策略，后者常从演示获得初始策略 | 本文提出的互补组合 |

本文建议先确定缺口，再决定是否需要世界模型：技能组合困难适合层级规划；空间精度不足优先改善几何与动作表示；示范少而有大量无动作视频，可考虑视频/潜表征预训练；任务需要比较多个行动后果，才值得承担规划的额外计算。**MoLe-VLA是动态层跳过的VLA效率技术，而非世界模型**，名称相似不能作为归类依据。[W034] 在需要人类协作、遮挡记忆、触觉和长期任务的场景，上述单一视觉路线都需要额外状态估计与反馈机制。
